# SevenAI

مشروع **SevenAI** هو منصة مساعد ذكي بواجهة ويب حديثة تعتمد على المكدس (Stack) الموضح أدناه. يهدف هذا المشروع إلى توفير نقطة انطلاق منظمة وقابلة للتوسّع لتطوير نظام يساعد المستخدمين عبر محادثة ذكية مدمجة مع خطط اشتراك متنوعة. البرنامج مصمم لكي يكون مصمماً ومتوافقاً مع القيم الإنسانية والأخلاقية، ويدعم اللغة العربية الفصحى بشكل افتراضي.

## المكدس التقني

- **الواجهة الأمامية (Frontend)**: React مع React Router وTailwind CSS.
- **الخلفية (Backend)**: Node.js مع Express.
- **قاعدة البيانات**: PostgreSQL.
- **المصادقة**: JSON Web Tokens (JWT) مع تشفير كلمات المرور باستخدام bcrypt.

## كيفية التشغيل

1. **التثبيت**

   في مجلد المشروع الرئيسي قم بتثبيت تبعيات الواجهة الأمامية والخلفية:

   ```bash
   cd backend
   npm install
   cd ../frontend
   npm install
   ```

2. **إعداد البيئة**

   - قم بإنشاء ملف `.env` داخل مجلد `backend` يعتمد على المثال الموجود في `.env.example`. يتضمن هذا الملف بيانات اتصال PostgreSQL ومفتاح JWT وأي مفاتيح خاصة بنموذج الذكاء.
   - يمكن إضافة ملف `.env` أيضًا للواجهة الأمامية إذا احتجت إلى متغيرات بيئة خاصة بها.

3. **تشغيل الخادم**

   ```bash
   # تشغيل قاعدة البيانات (يجب أن تكون لديك PostgreSQL مُثبتة)

   # في مجلد backend
   npm start
   ```

   سيبدأ خادم Express بالعمل على المنفذ المحدد في متغير البيئة `PORT` أو على 5000 افتراضيًا.

4. **تشغيل الواجهة الأمامية**

   في نافذة طرفية أخرى:

   ```bash
   cd frontend
   npm start
   ```

   سيبدأ تطبيق React على المنفذ 3000 افتراضيًا ويتصل بالخلفية عبر المسارات المحددة في الكود.

## ملفات رئيسية لتعديلها

- `backend/agent/sevenaiPersonality.js`: يحتوي على شخصية SevenAI كنص نظام. يمكن تعديل هذه الشخصية لتغيير أسلوب المساعد والقيم الأخلاقية.
- `backend/utils/plansConfig.js`: يعرّف خطط الاشتراك والأسعار والحدود. لتعديل الأسعار أو إضافة خطط جديدة قم بتحرير هذا الملف.
- `frontend/src/components` و`frontend/src/pages`: تحتوي على مكوّنات React وصفحات الواجهة. يمكن تعديل الألوان من خلال `tailwind.config.js`.

هذا المشروع يشكّل أساسًا جاهزًا للتطوير بحيث يمكنك بناء مساعد ذكي متكامل يعتمد على القيم الإنسانية ويدعم اللغة العربية الفصحى.
